辩论赛计时器

1 · 我的比赛版本
每个版本 = 一份完整配置(赛制 + 比赛信息 + 计时背景 + 投屏外观;封面/结束等整幅图就排在赛制的图文环节行里),互不覆盖。底部「保存为版本」把当前整份存下;▶ 用该版本直接开赛,「修改」载入继续编辑。
2 · 选择或编辑赛制
点击即载入为「可编辑副本」,改动需另存为我的赛制;内置不会被覆盖。
3 · 逐环节编辑 改名 / 选类型 / 填时长,均可
#环节名类型正方时长 反方时长先手操作
图片环节 = 全屏一整幅图(封面 / 结束用,每行可各自上传一张);文字环节 = 计时页背景 + 居中文字,顶部仍显示辩题与队名。内容环节不倒数,点「上一环 / 下一环」像翻页一样推进。
4 · 比赛信息与画面
内置
此背景用于所有计时环节与「文字环节」;封面 / 结束等图文页请到「3 · 逐环节编辑」里对该行单独上传整幅图(每行各传一张),行内也可改用内置底色。
5 · 投屏外观(可选) 只作用于比赛大屏,全局记忆,可一键恢复默认
辩题 / 队伍名位置 在下方假屏上拖动即可;中央灰带为计时区,不可覆盖

如何使用 · 转发给他人 / 换台电脑(点开)
  • 打开 / 自己用:双击 辩论赛计时器.html 即可,无需安装任何东西。
  • 转发工具本身:只需把 辩论赛计时器.html 这一个文件发给对方即可。用微信 / QQ 发送时,如果对方无法接收 .html 文件,可先压缩成 zip 再发送;对方解压后双击即可。
  • 只发 html,对方是从零开始:每个人的版本、上传的背景、外观只保存在当前这台电脑的浏览器里(不联网、不上传)。对方只拿到 html 时需自行配置赛制与比赛信息(但内置赛制可直接选用)。
  • 想把「整套配好的比赛」一起发过去:在卡片「1 · 我的比赛版本」找到对应那一行,点它的「导出」,浏览器会下载一个 名字.json;把这个 json 连同 html 一起发给对方。对方打开 html 后,在卡片 1 底部点「导入版本 JSON」选该文件,赛制、赛事名、辩题、队伍名、背景图、投屏外观会全部还原。
  • 备份 / 换电脑:重要版本随时可用「导出」留档;换电脑或重装浏览器后,用「导入版本 JSON」即可恢复。
