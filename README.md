# 辩论赛计时器

现场投屏用的辩论赛计时器，纯网页，无构建、无依赖、不联网。双击 `index.html` 即用；`release/辩论赛计时器.html` 是把所有代码打包进一个文件的单文件版，可单独拷给他人、双击即用。

## 快速上手
- 双击 `index.html`（开发）或 `release/辩论赛计时器.html`（单文件分发）
- 选择/编辑赛制 → 填赛事名、辩题、队伍名 → 「开始比赛 ▶」
- 全场是一条**可翻页的环节链**：计时环节（倒计时大数字）、图文环节（整幅图，封面/结束用）、文字环节（计时背景 + 居中文字），都在编辑页同一张表里增删、拖动排序
- 计时支持**固定时长**和**预算共用**两种模型；正/反方换边、暂停、自由辩论交替，全程单屏操作
- 投屏外观（辩题/队伍名位置、文字样式）可拖动自定义，也可一键恢复默认

## 转发 / 换电脑
- **只发工具本身**：把 `辩论赛计时器.html` 一个文件发给对方，双击即用
- **带整套配好的比赛**：在「我的比赛版本」里点「导出」得到 `名字.json`，连同 html 一起发；对方在编辑页底部「导入版本 JSON」即可全部还原
- 版本、上传的背景、外观只存在当前浏览器本地，不联网、不上传

## 内置赛制（可直接选用，只读）
- 华语辩论世界杯（参考模板，固定时长制）
- 国际华语辩论邀请赛 / 新国辩（预算池制，2025 起每队 18 分钟）

内置赛制只能以「可编辑副本」载入另存，不会覆盖原模板。

## 开发
- 引擎 `engine.js` 为纯函数状态机（无 DOM），逻辑与界面分离，改动前先写测试
- 测试：`node tests/engine.test.js`、`tests/presets.test.js`、`tests/appearance.test.js`、`tests/versions.test.js`（零依赖）
- 打单文件包：`node build-single.js` → 覆盖生成 `release/辩论赛计时器.html`

## 目录约定
- `engine.js` 计时引擎（纯逻辑） · `presets.js` 内置赛制 + 校验
- `app.js` 运行时投屏（计时/图文/文字三形态） · `editor.js` 赛制管理编辑
- `appearance.js` 投屏外观 · `versions.js` 版本存取
- `index.html` / `style.css` / `build-single.js` · `tests/` 测试 · `reference/` 参考站产物（只读）
